# Contributing Guidelines

* Fork the project.
* Make your feature addition or bug fix.
* Add tests for it. This is important so it does not break in a future version unintentionally.
* Commit just the modifications, do not mess with the composer.json or CHANGELOG.md files.
* Ensure your code is nicely formatted in the [PSR-2](https://www.php-fig.org/psr/psr-2/)
  style (`composer check-style`) and that all tests pass (`composer test`).
* Send the pull request.
* Check that the GitHub Actions build passed. If not, rinse and repeat.
